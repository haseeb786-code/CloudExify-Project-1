# 📊 Sales Data Analysis

## Project Overview

This project analyzes a retail sales dataset using Python to discover meaningful business insights. The analysis includes data cleaning, exploratory data analysis (EDA), visualization, and trend identification to support data-driven decision-making.

## Objectives

- Load and explore the sales dataset.
- Clean and preprocess the data.
- Perform exploratory data analysis (EDA).
- Identify monthly sales trends.
- Analyze product and regional performance.
- Generate business insights using visualizations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

**File:** `sales_data.csv`

The dataset contains information about:
- Order Date
- Product
- Category
- Region
- Sales
- Quantity

## Project Workflow

1. Import required libraries
2. Load dataset
3. Explore data
4. Handle missing values
5. Remove duplicates
6. Convert date columns
7. Perform statistical analysis
8. Analyze monthly sales
9. Identify top-selling products
10. Compare regional performance
11. Create visualizations
12. Summarize findings

## Key Insights

- Monthly sales trends were identified.
- Top-performing products contributed significantly to revenue.
- Sales varied across different regions.
- Product category analysis revealed major revenue contributors.
